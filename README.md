# Kamakiri Labs Homebrew tap

The Homebrew tap for the Kamakiri Pages command-line tool, `kamakiri`.

```
brew install kamakiri-labs/tap/kamakiri
```

The cask under `Casks/` is generated and pushed by the release workflow of
[kamakiri-labs/kamakiri](https://github.com/kamakiri-labs/kamakiri) on every
release, so nothing here is edited by hand. To report a problem with the
tool itself, use that repository.
